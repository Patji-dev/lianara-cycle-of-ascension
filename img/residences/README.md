# Residence paintings

27 original images generated for Lianara in a consistent Chinese shanshui ink-wash style. Warm rice paper, sepia brushwork, mountain mist and traditional buildings extend into celestial landscapes for later residences.

The source key to image mapping is maintained in `js/residence-art.js`. Each image is a separate original composition, not a crop from a shared sheet. WebP exports are 768 pixels wide; the original generated PNGs are retained outside the repository. The supplied reference painting guided the visual style and is not included in these assets.
